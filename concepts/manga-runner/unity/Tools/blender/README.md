# Ink Run model pipeline (Blender, headless)

All game meshes are generated by script in Blender, so every form decision is a number in a
file and the whole set rebuilds in under a minute. No Blender install needed: the `bpy` wheel
is Blender as a Python module.

```bash
pip install bpy                      # Blender 5.2 LTS as a module (~400 MB)
python3 Tools/blender/build_all.py   # writes Assets/InkRun/Models/*.glb
```

| File | What |
|---|---|
| `inklib.py` | Helpers: author in **Unity coordinates** (x right, y up, z forward); boxes with bevel/subsurf, cylinders, spheres, lofts, lathes, extruded profiles, NURBS tubes, skin chains, tori, modifiers (bevel, subsurf, solidify, mirror, boolean, array), `join` (applies stacks, merges parts with per-face materials, sets the pivot) and GLB export |
| `hero_bl.py` | Nozomi: skin-chain torso and limbs, lofted toon skull, tube hair, goggles, hoodie details. Exports joint nodes `Body/Head/LegL/LegR/ArmL/ArmR` that `HeroAnimator` rotates |
| `crew_bl.py` | Smudge Crew chaser (rival gang runner) derived from the hero build: bomber jacket, bandana, backwards cap, same joint nodes for `Chaser.cs` |
| `outfits_bl.py` | Wardrobe parts: Delivery (courier cap + strapped box), Ronin (headband with tails + bokken). Each GLB has Head/Body nodes that SceneBootstrap parents onto the hero's joints |
| `props_bl.py` | Train, Barrier, Sign, BuildingCity, Containers, BuildingAlley, Coin, Magnet, Dash, Lantern, KaijuShadow (flat silhouette for the Shadow sweep). Buildings get real boolean window reveals with glass and mullions; sizes match the trigger colliders in `SceneBootstrap.cs` |
| `review/` | three.js toon viewer + Playwright scripts that render contact sheets and a full in-game frame (`scene.html`) with the same ink look as the Unity shader |
| `gates.py` | Numeric gates from the reference-modeling skill, adapted to run headless: `mesh_report` (ngons, non-manifold, loose verts), `dim_gate` (bbox vs brief ±tol), `extent_profile` (taper, catches tubes), and `review()` Workbench clay/silhouette renders + a 450 px gameplay strip |
| `import_gen.py` | Post-processor for AI-generated GLBs (Tripo/Meshy/Hunyuan): normalise, ink-quantize the texture, quadric-decimate per material, split into the animator's joint nodes. See `GEN-PIPELINE.md` |
| `GEN-PIPELINE.md` | The image-to-3D route: measured Higgsfield costs, the Mac-session prompt, review loop |
| `BRIEF.md` | Phase-0 asset briefs: measured proportions, parts, silhouette features, budgets, gates and 'never' rules for the hero and every prop |
| `previews/` | Latest renders (`hero-sheet.png`, `props-sheet.png`, `scene-run.png`, `scene-jump.png`, `hero-clay.png` form check) |

Materials are named `InkPaper`, `InkAccent`, `Ink`, `InkTone`, `InkSkin`; `SceneBootstrap.RemapInk`
swaps them for the InkToon shader materials on import (glTFast package required).

Process (from the game-asset-modeling, reference-modeling and blender-image-to-3d skills, installed under
`~/.claude/skills/`): write the brief first; blockout to measured stations; pass the numeric gates
(`dim_gate`, `extent_profile`, `mesh_report`) before any detail; review clay + silhouette renders, never the
viewport; then hand the renders to a fresh-eyes critic subagent and work its ranked list until only minors
remain. Two critic rounds were run on these models; their findings drove v2-v6 of the hero and v2-v3 of the props (round 2 verified 5 of 14 earlier findings fixed, 7 partly; everything it ranked above minor is now applied).

Technique notes (from the modeling skills this pipeline follows): silhouette before detail,
Bevel before Subdivision, overlap parts at joins instead of abutting them, skin chains for organic
masses, spend triangles on the silhouette at the gameplay camera distance, review with rendered
evidence rather than the viewport. `Hero_LOD1.glb` / `Crew_LOD1.glb` are 12k / 8k decimations made by `import_gen.py`; `QualityPicker` swaps them in on low-end phones. Triangle counts: Hero 50k (subdivided; use Unity mesh LODs
or lower `subdiv` in `skin_chain` for low-end phones), props 1k–20k each.
